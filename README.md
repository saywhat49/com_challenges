# com_challenges

Composant Joomla 5 « Calendrier des challenges de boule de fort » (Fédération Française de Boule de Fort).

Statut : jalon 3 (administration + validation) livré, non testé en production. Voir les releases pour le ZIP installable.

Mise à jour : `update.xml` (à la racine de `main`) est lu par le serveur de mises à jour de Joomla ; chaque release publie un ZIP dont le SHA-256 est indiqué dans `update.xml`.
